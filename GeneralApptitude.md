# General Aptitude & Reasoning

# Part 1 — Quantitative Aptitude

## 1. Percentages ⭐⭐⭐⭐⭐

Percentage is one of the most useful topics because it connects to many other topics.

### Basic Formula

```text
Percentage = (Part / Whole) × 100
```

Example:

40 out of 80:

```text
(40 / 80) × 100 = 50%
```

---

### Percentage Increase

If the price changes from 200 → 250:

Increase:

```text
250 - 200 = 50
```

Percentage increase:

```text
(50 / 200) × 100 = 25%
```

---

### Percentage Decrease

If the value changes from 500 → 400:

Decrease:

```text
500 - 400 = 100
```

Percentage decrease:

```text
(100 / 500) × 100 = 20%
```

---

### Important Fractions to Memorize

| Fraction | Percentage |
| -------: | ---------: |
|      1/2 |        50% |
|      1/3 |     33.33% |
|      1/4 |        25% |
|      1/5 |        20% |
|      1/6 |     16.67% |
|      1/8 |      12.5% |
|     1/10 |        10% |
|     1/20 |         5% |
|     1/25 |         4% |

---

### Successive Percentage Change ⭐⭐⭐

If a value changes by `a%` and then by `b%`:

```text
Net % Change = a + b + (ab / 100)
```

Use a **negative value** for a decrease.

Example:

Increase by 20%, then decrease by 10%.

```text
Net % = 20 + (-10) + (20 × -10 / 100)
```

```text
= 20 - 10 - 2
= 8%
```

Therefore, the overall change is an **8% increase**.

# 2. Ratio ⭐⭐⭐⭐⭐

A ratio compares two quantities.

```text
a : b
```

Example:

If:

```text
Boys : Girls = 2 : 3
```

Total parts:

```text
2 + 3 = 5
```

If the total number of students is 50:

### Boys

```text
50 × (2 / 5) = 20
```

### Girls

```text
50 × (3 / 5) = 30
```

### Important Trick

If:

```text
a : b = 3 : 5
```

Then:

```text
a = 3x
b = 5x
```

This makes many ratio questions easier to solve.

# 3. Averages

Average commonly appears in numerical computation and estimation.

### Formula

```text
Average = Sum / Number of Values
```

Example:

```text
10, 20, 30, 40
```

Sum:

```text
10 + 20 + 30 + 40 = 100
```

Therefore:

```text
Average = 100 / 4 = 25
```

### Important Trick

If the average of 5 numbers is 20:

```text
Total = Average × Number of Values
```

```text
Total = 20 × 5 = 100
```

# 4. Powers & Exponents ⭐⭐⭐

Important rules:

```text
a^m × a^n = a^(m+n)
```

```text
a^m / a^n = a^(m-n)
```

```text
(a^m)^n = a^(m×n)
```

```text
a^0 = 1
```

```text
a^(-n) = 1 / a^n
```

### Example

```text
2^3 × 2^4
= 2^(3+4)
= 2^7
= 128
```

---

# 5. Logarithms ⭐⭐⭐

Important rules:

```text
log_a(xy) = log_a(x) + log_a(y)
```

```text
log_a(x/y) = log_a(x) - log_a(y)
```

```text
log_a(x^n) = n × log_a(x)
```

Most importantly:

```text
log_a(a) = 1
```

```text
log_a(1) = 0
```

### Example

```text
log_2(8) = 3
```

because:

```text
2^3 = 8
```

# 6. Permutations ⭐⭐⭐⭐

Permutation means **arrangement**.

### Formula

```text
nPr = n! / (n-r)!
```

Example:

Arrange 3 people from 5:

```text
5P3 = 5! / (5-3)!
```

```text
= 5! / 2!
= 60
```

### Remember

> **P = Position**

Order matters in permutations.

---

# 7. Combinations ⭐⭐⭐⭐

Combination means **selection**.

### Formula

```text
nCr = n! / [r!(n-r)!]
```

Example:

Choose 3 people from 5:

```text
5C3 = 5! / [3! × 2!]
```

```text
= 10
```

### Remember

> **C = Choose**

Order does **not** matter in combinations.

### Important Relationship

```text
nPr = nCr × r!
```

# 9. Probability ⭐⭐⭐⭐⭐

Probability is an important aptitude topic.

### Basic Formula

```text
P(E) = Favourable Outcomes / Total Outcomes
```

Example:

A fair die has six possible outcomes.

Probability of getting 4:

```text
P(4) = 1/6
```

---

### Probability of an Even Number

Possible even outcomes:

```text
2, 4, 6
```

Therefore:

```text
P(Even) = 3/6 = 1/2
```

---

### Complement

```text
P(Not A) = 1 - P(A)
```

Example:

Probability of rain = 0.3.

Probability of no rain:

```text
1 - 0.3 = 0.7
```

# 10. Statistics ⭐⭐⭐

Important basic concepts:

* Mean.
* Median.
* Mode.

---

## Mean

```text
Mean = Sum / Number of Values
```

---

## Median

First, arrange the numbers in ascending order.

Example:

```text
3, 5, 7, 9, 11
```

Median:

```text
7
```

### For an Even Number of Values

Example:

```text
2, 4, 6, 8
```

The two middle values are 4 and 6.

```text
Median = (4 + 6) / 2
       = 5
```

---

## Mode

The **mode** is the value that occurs most frequently.

Example:

```text
2, 3, 3, 4, 5
```

Mode:

```text
3
```

# 15. Analogy ⭐⭐⭐⭐

An analogy asks you to identify the relationship between two things and apply the same relationship to another pair.

Example:

```text
Doctor : Hospital
Teacher : ?
```

A doctor works in a hospital.

Similarly, a teacher works in a:

```text
School
```

Answer:

**School**

### Approach

Ask yourself:

> What is the relationship between the first pair?

Then apply the same relationship to the second pair.

# 16. Deduction

Deduction moves from a **general statement to a specific conclusion**.

Example:

```text
All cats are animals.

Tom is a cat.

Therefore:

Tom is an animal.
```

Basic structure:

```text
General Statement
       ↓
Specific Case
       ↓
Conclusion
```

---

# 17. Induction

Induction generally moves from **observations to a general conclusion**.

Basic structure:

```text
Observations
      ↓
Identify Pattern
      ↓
General Conclusion
```

For aptitude exams, focus on identifying patterns and determining whether a conclusion logically follows from the given observations.

# 18. Spatial Reasoning ⭐⭐⭐⭐

Spatial reasoning is an important reasoning area.

Practice:

* Mirror images.
* Rotations.
* Paper folding.
* Paper cutting.
* Shape assembly.
* Pattern matching.
* 2D → 3D visualization.
* 3D → 2D visualization.
* Scaling.
* Translation of shapes.

### Exam Strategy

For difficult spatial questions, use **elimination**.

Instead of trying to mentally visualize everything at once:

1. Check the orientation.
2. Check the number of sides/features.
3. Check the position of distinctive marks.
4. Eliminate impossible options.
5. Compare the remaining options.

# 20. Articles

## A

Used before a consonant sound.

Example:

> a university

Although `university` begins with the letter `u`, it starts with a **"yu" sound**, so we use `a`.

---

## An

Used before a vowel sound.

Example:

> an apple

> an hour

The important rule is:

> Articles depend on the **sound**, not simply the first letter.

---

## The

Used when referring to something specific or already identified.

Example:

> The book on the table.

# 22. Subject-Verb Agreement ⭐⭐⭐⭐

The verb must agree with the subject in number.

### Singular

> He **plays** cricket.

### Plural

> They **play** cricket.

### Common Exam Trap

Correct:

> Each of the students **is** present.

Incorrect:

> Each of the students **are** present.

Remember:

> **Each** is treated as singular.

# 25. Narrative Sequencing

You may receive several sentences that need to be arranged in the correct order.

Example:

```text
A. He reached the station.
B. He purchased a ticket.
C. He boarded the train.
D. He left his house.
```

Correct sequence:

```text
D → A → B → C
```

### Strategy

Look for the natural sequence:

```text
Cause
  ↓
Action
  ↓
Next Action
  ↓
Result
```

For example:

```text
Leave home
    ↓
Reach station
    ↓
Buy ticket
    ↓
Board train
```
